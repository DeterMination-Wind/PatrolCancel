# PatrolCancel v1.0.0 — Release Notes / 发布说明

[中文](#中文) | [English](#english)

## 中文

**PatrolCancel 1.0.0**：右键移动解除巡逻。

右键指挥选中单位时，自动解除选中可指挥单位的巡逻（Patrol）姿态，让它们立即服从右键移动/攻击命令，不再卡在巡逻循环里——原版右键命令不会清除巡逻姿态，这是巡逻单位“右键拽不动”的原因。

## English

**PatrolCancel 1.0.0**: Right-click cancels patrol.

Right-clicking to command selected units clears their Patrol stance automatically, so they immediately obey move / attack orders instead of staying stuck in the patrol loop — vanilla right-click commands never clear the Patrol stance, which is why patrolling units used to ignore them.
